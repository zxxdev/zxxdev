### Hi, I'm zxxdev

Systems engineer building backend services and the platforms they run on.

I've spent years on the operations side: running infrastructure, supporting users and building web projects. Now I write software for the problems I used to solve by hand — support workflows, deployments, observability and automation.

#### How I work

- **Tested by default.** Every repo has CI, and the progress badges in my READMEs are computed by the pipeline, never typed by hand.
- **Decisions written down.** Important technical choices are recorded as short ADRs, including what they cost.
- **AI-assisted, human-reviewed.** I use AI coding agents in my day-to-day work; tests, CI and review are the guardrails.
